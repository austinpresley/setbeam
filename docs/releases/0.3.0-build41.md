# Setbeam 0.3.0 build 41

Apple Silicon, macOS 14 or later. Developer prerelease, signed with Developer
ID and notarized by Apple.

[Download the Mac app](https://github.com/austinpresley/setbeam/releases/download/v0.3.0-build41/Setbeam-0.3.0-build41.dmg)
· [Installation and setup](https://github.com/austinpresley/setbeam/blob/v0.3.0-build41/docs/getting-started.md)

## Install and update

- Open the disk image and drag Setbeam to Applications. macOS opens it
  normally; you no longer need Open Anyway in Privacy & Security.
- Setbeam checks for signed updates once a day. Choose Setbeam → Check for
  Updates… to check now, or turn automatic checks off in Settings → Updates.
  Installing an update quits and reopens the app.
- An update found while you're sharing waits in the menus and never interrupts
  the share. If you install one during a share, Setbeam asks before ending it.
- Build 40 and earlier can't update themselves. Install this build once by
  hand; later builds arrive in the app.
- The new signature means macOS asks again for Screen Recording, Camera,
  Microphone, Local Network and Location access the first time each is needed.

## Changes since build 40

Build 41 adds notarized installation and in-app updates. Monitoring, sharing,
viewer access and media behavior are unchanged from build 40, including its
memory and viewer-approval fixes. See the
[build 40 notes](https://github.com/austinpresley/setbeam/blob/v0.3.0-build41/docs/releases/0.2.0-build40.md).

## Limits

Hardware compatibility is unchanged. Physical iOS/Safari and keyboard tests,
audible native output and A/V timing, long transmitter sessions, physical 4K
devices, wider capture hardware, older macOS and Intel support remain separate
qualification. See [hardware tests](https://github.com/austinpresley/setbeam/blob/v0.3.0-build41/docs/hardware-tests.md).
