# Setbeam 0.3.1 build 43

Apple Silicon, macOS 14 or later.

- Choose a screen, window, camera, wireless source, or labeled sample from the Mac’s monitor. Go Live starts sharing, and the live tally opens Hold and Stop Sharing.
- Invite puts the Wi-Fi and viewing codes together. People keeps join requests above admitted viewers and shows the playback reported by each viewing session.
- The browser viewer gives the picture more room. On an upright phone, chat stays below the picture. On larger screens, the controls fade when idle.
- An admitted Android TV receiver can show the live picture, read session chat, and display shared pointers. Setbeam Receiver 0.2.1 is a separate developer APK.

## Install

Open the disk image and drag Setbeam to Applications. Build 41 added signed in-app updates. Builds 40 and earlier need a manual install. Setbeam keeps a scheduled update in the menu while a share is running.

See the [setup guide](https://github.com/austinpresley/setbeam/blob/v0.3.1-build43/docs/getting-started.md) for joining a feed and the [physical test record](https://github.com/austinpresley/setbeam/blob/v0.3.1-build43/docs/hardware-tests.md) for tested routes and devices.
