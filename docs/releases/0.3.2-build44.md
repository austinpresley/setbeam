# Setbeam 0.3.2 build 44

Apple Silicon, macOS 14 or later.

- Choose a screen, window, camera, wireless source, or labeled sample from the Mac’s monitor. Go Live opens the Wi-Fi and Watch codes. Use the LIVE menu to Hold or Stop Sharing while your Mac keeps monitoring the source.
- Hold cuts the outgoing picture and sound sooner and resumes on the same viewing link. The Mac’s outgoing preview switches in the background so its controls stay responsive.
- Browser viewers can start watching as soon as the share is ready. When Ask first is on, approve viewers in People. You can also see the resolution, frame rate, and dropped frames each browser reports.
- Setbeam uses hardware video decoding for eligible previews and locally captured feeds. It retries with software when the hardware path fails. Preview video also uses less temporary memory.
- Highlight my cursor follows your pointer when sharing a screen or window. On phones the viewer’s chat sits below the picture, and on larger screens the controls fade when idle.

## Install

Open the disk image and drag Setbeam to Applications. Installations on build 41 or later can update from **Setbeam → Check for Updates…**. Builds 40 and earlier need a manual install. A scheduled update appears in the menu while you’re sharing.

See the [setup guide](https://github.com/austinpresley/setbeam/blob/v0.3.2-build44/docs/getting-started.md) and [physical test record](https://github.com/austinpresley/setbeam/blob/v0.3.2-build44/docs/hardware-tests.md).
