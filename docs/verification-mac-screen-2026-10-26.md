# This Mac's screen verification

## Implementation

An in-app ScreenCaptureKit display stream excludes Setbeam's application windows, includes the cursor, and sends VideoToolbox H.264 through an explicit stdin pipe to the supervised bundled FFmpeg publisher. The one local relay serves native main/floating monitoring and audience sharing. Display UUIDs are saved through SourceSetup and ProvenSetupStore. See architecture.md for capture dimensions, cadence, bitrate, backpressure, and permission attribution.
